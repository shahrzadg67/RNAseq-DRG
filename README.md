# TUY35595 — Mouse DRG/Nerve RNA-seq (MINP / SNI / Sham)

Bulk RNA-seq comparing **MINP** (nucleus pulposus) vs **Sham** (plus **SNI** for QC) in male and
female mouse DRG/nerve, with an interactive Shiny app for exploring the results.

**▶ Live app:** https://shahrzadghs.shinyapps.io/tuy35595-rnaseq/

---

## Methods (brief)
- **Pipeline:** nf-core/rnaseq v3.19.0 (Trim Galore → STAR → Salmon), mouse **GRCm39, Ensembl 116**;
  gene- and transcript-level quantification.
- **Differential expression:** DESeq2 and edgeR/limma-voom (side-by-side).
- **Batch correction:** the biological replicate = a dated **processing cohort**; it drove ~60% of
  PC1. It is modelled as an additive covariate in DE and removed with `limma::removeBatchEffect`
  for PCA/boxplots. **Sex chromosomes removed** in the corrected analysis; **SNI excluded** from DE.
- **Enrichment:** clusterProfiler `gseGO`/`gseKEGG` (+ org.Mm.eg.db).
- Full rationale and findings are in the app's **Methods** and **Summary of Results** tabs.

Rscript analysis/run_all_noxy.R    # batch-corrected + sex chromosomes removed

## Pipeline run (nf-core/rnaseq) — raw reads → count matrices
Goal: gene-level **and** transcript-level count matrices in one run (14 paired-end samples).

```bash
cd <project root>
# 1. Decompress ORA -> fastq.gz  (Slurm array)
sbatch scripts/01_ora_to_fastq.sh
# 2. Download mouse GRCm39 reference — on the data-mover node
bash scripts/02_get_reference.sh
# 3. Pre-pull pipeline + Singularity containers
bash scripts/03_prestage_pipeline.sh
# 4. samplesheet.csv is generated (re-run scripts/04 if fastq names change)
# 5. Smoke test (validates Slurm + Singularity + caches)
sbatch scripts/05_smoke_test.sh
# 6. Real run (Slurm job, survives logout)
sbatch run_rnaseq.sh
# 7. Reclaim space (deletes work/ only)
bash scripts/06_cleanup_after_success.sh
```
**Outputs** in `results/star_salmon/`: `salmon.merged.{gene,transcript}_counts.tsv` (+ TPMs), `.rds`
SummarizedExperiments, per-sample Salmon dirs, and `results/multiqc/`. Slurm account = `msalter`;
`--save_reference` caches the STAR+Salmon indices under `results/genome/` for fast re-runs.
